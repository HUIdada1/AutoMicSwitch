# AutoMicSwitch 规则配置
#
# 用法：把本文件复制成 rules.txt，放到 AutoMicSwitch.exe 同一个目录，重启程序生效。
#
# 规则格式，一行一条：
#     播放设备关键字|目标麦克风关键字|说明
#
# 关键字匹配的是设备硬件路径（InstanceId）的子串，一般写 VID_XXXX 就够了。
# 换 USB 口、改设备显示名、重装驱动都不会影响匹配。
#
# 兜底规则（可选，最多一条）：
#     fallback=VID_XXXX    播放设备没匹配到任何规则时，麦克风切到这里
#     fallback=none        没匹配到时保持不动
#
# 以 # 开头的行是注释，空行会被忽略。

# 怎么查 VID：
#   设备管理器 -> 选中设备 -> 右键「属性」->「详细信息」->「硬件 Id」
#   会看到类似 USB\VID_1234&PID_5678 的字符串，取 VID_1234 即可。

# ---- 联动规则（把 VID 换成你自己的）----
# VID_1234|VID_1234|耳机播放时用耳机自己的麦克风
# VID_5678|VID_5678|另一副耳机

# ---- 兜底 ----
# fallback=VID_9ABC
